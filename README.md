# 智能提词器 Pro (Teleprompter)

一个基于原生 Web 技术栈构建的进阶版提词器应用。支持自动滚动、焦点高亮、全屏沉浸模式、主题切换、镜像模式和丰富的键盘快捷键控制。

## 高级功能 (Advanced Features)
- ✅ **自动滚动与平滑动画**：基于 requestAnimationFrame 的流畅滚动体验。
- ✅ **焦点行高亮**：屏幕中央的文本自动加粗高亮，帮助演讲者聚焦当前朗读位置。
- ✅ **沉浸式专注模式**：一键隐藏所有工具栏和状态栏，实现零干扰演讲。
- ✅ **浅色/深色主题切换**：适应不同光线环境（如明亮的演播室或暗光房间）。
- ✅ **镜像模式**：将文字水平翻转，适配物理分光镜提词硬件。
- ✅ **动态字号调节**：通过滑块实时调整文字大小，适应不同视力需求。
- ✅ **全屏模式**：一键进入全屏，获得沉浸式体验。

## 技术栈 (Tech Stack)
- HTML5 (语义化标签、模块化结构)
- CSS3 (CSS 变量、Flexbox 布局、渐变遮罩、过渡动画)
- JavaScript ES6+ (requestAnimationFrame、LocalStorage、DOM 动态计算)
