# 智能提词器 (Teleprompter)

一个基于原生 Web 技术栈构建的轻量级提词器应用。支持自动滚动、速度调节、键盘快捷键控制，适合演讲、直播和视频录制场景。

## 功能特性 (Features)
- ✅ **自动滚动**：平滑的逐帧动画，支持 1-10 级速度调节。
- ✅ **键盘快捷键**：空格键播放/暂停，上下键调速，R 键重置。
- ✅ **响应式布局**：适配不同屏幕尺寸，界面简洁易用。
- ✅ **状态提示**：底部状态栏实时显示当前运行状态。

## 技术栈 (Tech Stack)
- HTML5 (语义化标签)
- CSS3 (Flexbox 布局、渐变遮罩、动画过渡)
- JavaScript ES6+ (requestAnimationFrame、模块化状态管理)
